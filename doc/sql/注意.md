# 数据库初始化与使用指南

本项目提供多数据库方言支持（MySQL、达梦 DM8、Oracle、SQL Server），各数据库初始化脚本均存放在当前目录对应子文件夹中。

## 初始化执行步骤

### 1. 创建数据库 / Schema

根据所选数据库类型，进入对应目录，**优先执行** `1.先执行我,创建数据库.sql`：
- 创建 Nacos 配置数据库：`lamp_nacos`
- 创建链路追踪数据库（可选）：`lamp_sw`
- 创建核心业务数据库：`lamp_none`

### 2. 导入核心业务表结构与初始化数据

连接至已创建的 `lamp_none` 数据库，执行对应的 `lamp_none.sql`：
- 导入系统核心表（用户、角色、权限、机构、数据权限、代码生成、站内信、字典等）
- 导入内置超级管理员与基础菜单权限数据

### 3. Nacos 配置文件导入

若采用外部 MySQL 存储 Nacos 配置：
1. 在 Nacos 控制台新建命名空间或直接使用公共空间。
2. 可直接在 Nacos 控制台导入 `doc/third-party/nacos/nacos_config_export_*.zip` 配置压缩包。
3. 检查并修改 Nacos 中的数据库连接 IP、端口及密码，确保与本地/服务器真实数据库一致。

## 各数据库注意事项

### 1. MySQL

- **版本建议**：推荐 **MySQL 8.0+**。
- **排序规则**：
  - `lamp_none.sql` 默认使用 `utf8mb4_0900_ai_ci` 排序规则（MySQL 8.0 特性）。
  - 若在 **MySQL 5.7** 环境下运行，请在导入前全局批量将 `utf8mb4_0900_ai_ci` 替换为 `utf8mb4_general_ci`。
- **参数配置**：
  - 确保 `lower_case_table_names=1`（表名大小写不敏感，Linux 环境部署前需在 `my.cnf` 中配置并初始化）。
  - `max_allowed_packet` 建议调大至 `64M` 或以上，防止大批量数据插入报错。

### 2. 达梦数据库 (DM8)

- **实例属性**：
  - 创建达梦数据库实例时，**“大小写敏感”参数必须选择“否”**（`CASE_SENSITIVE=0`），否则由于 SQL 语句字段未加双引号会导致找不到列或表报错。
  - 字符集推荐选择 `UTF-8`。
- **Schema 授权**：
  - 确保执行账号对 `lamp_none` Schema 拥有完整的 DDL / DML 权限。

### 3. Oracle (12c / 19c / 21c)

- **组件选型**：
  - Nacos 官方暂无内置 Oracle 持久化驱动，**强烈建议 Nacos 使用 MySQL 存储，核心业务使用 Oracle**。
- **CDB / PDB 容器架构**：
  - 若在多租户容器数据库执行脚本，请先切换到业务 PDB，或以 SYSDBA 执行 `ALTER SESSION SET "_ORACLE_SCRIPT"=true;` 后创建独立用户。

### 4. SQL Server (2016+)

- **排序规则**：
  - 推荐使用 `Chinese_PRC_CI_AS`。
- **组件配合**：
  - 同 Oracle，Nacos 推荐搭配 MySQL 使用，业务系统连接 SQL Server。

## 初始账号说明

导入 `lamp_none.sql` 后，默认内置系统管理员账号：
- **用户名**：`admin`
- **默认密码**：以 Nacos/工程配置或系统初始化密码为准（建议首次登录后立即修改密码）
