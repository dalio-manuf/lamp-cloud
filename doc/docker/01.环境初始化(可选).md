# 01. Docker 宿主机系统初始化（可选）

> [!WARNING]
> **生产环境慎重执行**：本文档提供的初始化脚本（如关闭防火墙、修改内核参数、关闭 SELinux 等）适用于全新测试机或云服务器初始化。若为正在运行其他生产业务的宿主机，请按需选择并严格评估网络与安全策略后再行操作！

---

## 1. 主机名与 Hosts 解析配置

设置持久化主机名，便于多节点识别与维护：

```bash
# 设置主机名（例如 node-docker-01）
hostnamectl set-hostname node-docker-01

# 配置 /etc/hosts 本地解析（将 IP 替换为实际内网 IP）
cat >> /etc/hosts <<EOF
192.168.10.101 node-docker-01
EOF
```

---

## 2. 基础依赖包安装

安装常用系统工具与网络依赖：

```bash
yum install -y epel-release curl wget vim net-tools telnet \
  conntrack ipvsadm ipset jq iptables sysstat libseccomp
```

---

## 3. 防火墙与网络安全策略

在内网受信环境下或通过云安全组管理端口时，可按需关闭系统本地防火墙并放行流量转发：

```bash
# 停止并禁用 firewalld
systemctl stop firewalld
systemctl disable firewalld

# 设置默认转发策略为 ACCEPT（防止容器间通信被拦截）
iptables -P FORWARD ACCEPT
```

---

## 4. 禁用 SELinux

避免容器挂载宿主机目录时出现 `Permission denied` 权限报错：

```bash
# 临时关闭
setenforce 0

# 永久关闭（重启后仍生效）
sed -i 's/^SELINUX=.*/SELINUX=disabled/' /etc/selinux/config
```

---

## 5. 内核网络模块与转发参数优化

加载桥接与 IPVS 相关内核模块，确保容器网络流量能够正常桥接和路由：

```bash
# 启用必要的内核模块
modprobe br_netfilter
modprobe ip_vs

# 配置内核网络与虚拟内存参数
cat > /etc/sysctl.d/99-docker.conf <<EOF
net.bridge.bridge-nf-call-iptables = 1
net.bridge.bridge-nf-call-ip6tables = 1
net.ipv4.ip_forward = 1
vm.max_map_count = 262144
fs.file-max = 6553600
EOF

# 应用配置生效
sysctl --system
```

---

## 6. 系统时区与时间同步

统一各节点与容器的时区，避免分布式微服务因时钟不同步导致 Token 失效或日志错乱：

```bash
# 设置时区为亚洲/上海
timedatectl set-timezone Asia/Shanghai
timedatectl set-local-rtc 0

# 安装并启动 chrony 时间同步服务
yum install -y chrony
systemctl enable chronyd --now

# 检查时间同步状态
chronyc tracking
```

---

## 7. 文件描述符与进程数限制 (Limits)

微服务与高并发中间件（如 MySQL、Redis、RabbitMQ、Nacos）需要充足的文件描述符：

```bash
cat >> /etc/security/limits.conf <<EOF
* soft nofile 655350
* hard nofile 655350
* soft nproc  655350
* hard nproc  655350
* soft memlock unlimited
* hard memlock unlimited
EOF
```
