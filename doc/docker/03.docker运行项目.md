# 03. Docker 容器化运行项目指南

本文档介绍如何通过 Docker 将 `lamp-cloud` 各微服务打包为容器镜像并完成编排运行。

---

## 1. 基础中间件环境准备

在运行业务微服务前，必须先启动基础中间件（Nacos、MySQL、Redis、RabbitMQ）。

> [!TIP]
> 推荐直接使用项目提供的 Docker Compose 一键启动中间件：
> ```bash
> cd doc/dockerfile
> # 复制环境配置模板（按需修改密码与端口）
> cp .env.example .env
> # 一键后台启动所有中间件
> docker compose up -d
> ```
> 详细配置与各中间件独立脚本请参见 [doc/dockerfile/README.md](../README.md#dockerfile)。

---

## 2. 数据库与 Nacos 配置初始化

1. **数据库导入**：
   - 参考 [doc/sql/注意.md](../sql/注意.md)，在 MySQL 实例中优先执行 `doc/sql/mysql/1.先执行我,创建数据库.sql`，再导入核心业务表 `doc/sql/mysql/lamp_none.sql`。
2. **Nacos 配置导入**：
   - 登录 Nacos 控制台（默认 `http://<IP>:8848/nacos`，账号密码默认 `nacos/nacos`）。
   - 导入 `doc/third-party/nacos/nacos_config_export_*.zip`。
   - 检查并修改 `common.yml`、`mysql.yml`、`redis.yml` 中的连接 IP 与密码（在 Docker 容器网络中，不可配置为 `127.0.0.1`）。

---

## 3. 微服务打包构建

在项目**根目录**下执行 Maven 打包命令：

```bash
mvn clean package -DskipTests
```

构建完成后，各子服务的 `target/` 目录下将生成可执行的 Spring Boot JAR 包。

---

## 4. 构建微服务 Docker 镜像

各核心微服务子工程均提供了标准的 `Dockerfile`（基于 Eclipse Temurin JDK 17 JRE 构建）。进入各服务模块执行镜像构建：

```bash
# 1. 构建网关服务镜像
cd lamp-gateway/lamp-gateway-server
docker build --build-arg JAR_FILE=target/lamp-gateway-server.jar -t lamp-gateway-server:v1 .

# 2. 构建认证授权服务镜像
cd ../../lamp-oauth/lamp-oauth-server
docker build --build-arg JAR_FILE=target/lamp-oauth-server.jar -t lamp-oauth-server:v1 .

# 3. 构建系统管理服务镜像
cd ../../lamp-system/lamp-system-server
docker build --build-arg JAR_FILE=target/lamp-system-server.jar -t lamp-system-server:v1 .

# 4. 构建基础服务镜像（若提供独立 Dockerfile）
cd ../../lamp-base/lamp-base-server
docker build --build-arg JAR_FILE=target/lamp-base-server.jar -t lamp-base-server:v1 .

# 5. 构建服务监控中心镜像
cd ../../lamp-support/lamp-monitor
docker build --build-arg JAR_FILE=target/lamp-monitor.jar -t lamp-monitor:v1 .
```

---

## 5. 启动微服务容器

按推荐依赖顺序启动服务容器（将环境变量中的 `${HOST_IP}` 替换为宿主机局域网 IP，不可填 `127.0.0.1`）：

### 5.1 启动统一网关 (Gateway)

```bash
docker run -d --name lamp-gateway-server --restart=always \
  -e SPRING_PROFILES_ACTIVE=docker \
  -e NACOS_ADDR=${HOST_IP}:8848 \
  -p 8760:8760 \
  -v /data/logs/lamp-gateway:/logs \
  lamp-gateway-server:v1
```

### 5.2 启动认证授权服务 (OAuth)

```bash
docker run -d --name lamp-oauth-server --restart=always \
  -e SPRING_PROFILES_ACTIVE=docker \
  -e NACOS_ADDR=${HOST_IP}:8848 \
  -p 8764:8764 \
  -v /data/logs/lamp-oauth:/logs \
  lamp-oauth-server:v1
```

### 5.3 启动核心系统服务 (System)

```bash
docker run -d --name lamp-system-server --restart=always \
  -e SPRING_PROFILES_ACTIVE=docker \
  -e NACOS_ADDR=${HOST_IP}:8848 \
  -p 8766:8766 \
  -v /data/logs/lamp-system:/logs \
  lamp-system-server:v1
```

### 5.4 启动基础支撑服务 (Base)

```bash
docker run -d --name lamp-base-server --restart=always \
  -e SPRING_PROFILES_ACTIVE=docker \
  -e NACOS_ADDR=${HOST_IP}:8848 \
  -p 8768:8768 \
  -v /data/logs/lamp-base:/logs \
  lamp-base-server:v1
```

### 5.5 启动服务监控中心 (Monitor)

```bash
docker run -d --name lamp-monitor --restart=always \
  -e SPRING_PROFILES_ACTIVE=docker \
  -e NACOS_ADDR=${HOST_IP}:8848 \
  -p 8762:8762 \
  -v /data/logs/lamp-monitor:/logs \
  lamp-monitor:v1
```

---

## 6. 服务验证与健康检查

1. **查看容器运行状态**：
   ```bash
   docker ps -a
   ```
2. **查看服务实时日志**：
   ```bash
   docker logs -f --tail=100 lamp-gateway-server
   ```
3. **Nacos 服务列表核对**：
   登录 Nacos 管理控制台 -> 服务管理 -> 服务列表，确认所有启动的微服务已正常上线且健康状态为 true。
