# 02. Docker 与 Docker Compose 安装部署指南

本文档介绍如何在 Linux 服务器上安装最新稳定版 **Docker Community Edition (Docker CE)** 与 **Docker Compose**。

---

## 方案一：自动化脚本一键安装（推荐）

适用于大部分主流 Linux 发行版（CentOS、RHEL、Ubuntu、Debian 等），采用阿里云镜像加速源自动安装：

```bash
# 使用官方脚本并通过阿里云镜像加速安装
curl -fsSL https://get.docker.com | bash -s docker --mirror Aliyun
```

---

## 方案二：YUM 仓库手动安装（CentOS / RHEL / Rocky）

### 1. 卸载旧版本（若存在）

```bash
yum remove -y docker docker-client docker-client-latest docker-common \
  docker-latest docker-latest-logrotate docker-logrotate docker-engine
```

### 2. 设置 Docker CE YUM 源

```bash
yum install -y yum-utils device-mapper-persistent-data lvm2
yum-config-manager --add-repo https://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo
```

### 3. 安装 Docker CE 及客户端插件

```bash
yum install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

---

## 配置 Docker 守护进程 (daemon.json)

配置 Docker 国内镜像加速器、日志文件限制与存储路径，避免磁盘被容器日志占满：

```bash
mkdir -p /etc/docker

cat > /etc/docker/daemon.json <<EOF
{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://mirror.ccs.tencentyun.com",
    "https://hub-mirror.c.163.com"
  ],
  "log-driver": "json-file",
  "log-opts": {
    "max-size": "100m",
    "max-file": "3"
  },
  "max-concurrent-downloads": 10,
  "live-restore": true
}
EOF
```

---

## 启动与设置开机自启

```bash
# 重载 systemd 配置并启动 Docker
systemctl daemon-reload
systemctl enable docker --now

# 查看 Docker 服务状态
systemctl status docker
```

---

## 验证安装结果

运行以下命令确认 Docker 与 Docker Compose 正确安装：

```bash
# 查看 Docker 版本
docker version

# 查看 Docker Compose 版本
docker compose version

# 运行 hello-world 测试镜像
docker run --rm hello-world
```
